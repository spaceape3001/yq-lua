# Your Quill's Lua Submodule

**Effective 09-Nov-2025, functionality of this repo is being absorbed into the toolbox & vulkan repos.**  This is due to the need to more tightly integrate it into other projects (without having to create many, many, other submodules).

This is the submodule for the YourQuill project, provides Lua bindings, functions, etc.

## Dependencies

* YourQuill Repositories:
    - Toolbox (Required)
    - Vulqan (Optional)
* Lua (Required)
